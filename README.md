# Minecraft Launcher 1.5.2 (базовый)

Теперь это не просто статическая страница: добавлен локальный Node.js-сервер с API, который умеет:

- **выгружать (скачивать) версию 1.5.2** в указанную папку клиента;
- **запускать Minecraft 1.5.2** через `minecraft-launcher-core`.

## Что есть в UI

- никнейм;
- путь к папке клиента Minecraft;
- путь к Java (опционально);
- RAM;
- полноэкранный режим;
- кнопки:
  - `Выгрузить 1.5.2`;
  - `Запустить 1.5.2`.

## Запуск

```bash
npm install
npm start
```

Откройте в браузере: <http://localhost:3000>

## Важно

- Для реального запуска нужен установленный Java Runtime (обычно Java 8 для старых версий).
- Кнопка "Выгрузить 1.5.2" скачивает версионные файлы (`1.5.2.json` и `1.5.2.jar`) в структуру папки клиента.
- При запуске `minecraft-launcher-core` может дополнительно докачивать отсутствующие зависимости.

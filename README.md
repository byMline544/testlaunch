# Базовый Minecraft Launcher (1.5.2)

Минимальный прототип лаунчера с возможностями:

- ввод никнейма;
- выбор версии игры (по умолчанию 1.5.2);
- указание пути к клиенту через кнопку выбора папки;
- базовые настройки запуска (путь к Java, RAM, полноэкранный режим);
- кнопка "Запустить игру" с выводом итоговой конфигурации и примера команды.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

И откройте: <http://localhost:8080>
